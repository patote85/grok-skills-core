# Common Failure Modes to Avoid

- **The Kitchen Sink** — Asked for a feature, restructured half the codebase.
- **The Wrong Abstraction** — Beautiful generic solution for a problem that exists in only one place.
- **The Invisible Decision** — Made an architectural choice without signalling it.
- **The Optimistic Path** — Handled only the happy path.
- **The Knowledge Hallucination** — Used an API or parameter that does not exist.
- **The Style Drift** — Wrote in personal style instead of the project’s style.
- **The Runaway Refactor** — Started in one place and ended changing 15 files.
